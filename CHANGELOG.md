# Changelog

## 0.3.1

- Allow creating an empty folder first and filling it with explicit chats later.

## 0.3.0

- Inspect and analyze Telegram chats for folder organization.
- Preview, create, update, populate, reorder and delete native Telegram folders.
- Apply a reviewed folder plan with protected default and Archive tabs.
- Create encrypted local folder snapshots and restore them by backup ID.
- Keep folder operations inside the selected local chat access scope.

## 0.2.0

- Read chats, history and message context; search and download attachments.
- Prepare and send plain-text messages and replies on explicit user instruction.
- Persist encrypted drafts and delivery results; prevent retry of uncertain sends.
- Connect an individual account through a local Windows setup wizard.
- Provide a Windows installer and Russian documentation for GitHub distribution.

## 0.1.0

- Initial read-only Telegram integration.
