Версия 0.2 · Чтение и отправка

Чаты, поиск, вложения и отправка сообщений по твоему поручению. В этом окне ты входишь напрямую в Telegram через локальный инструмент.

Аккаунт уже подключён

Можно изменить список доступных чатов или завершить эту сессию Telegram.

1. Данные приложения

Открой my.telegram.org → API development tools, создай приложение и скопируй API ID и API Hash.

2. Код подтверждения

Введи код, который прислал Telegram. Не отправляй его в чат Codex.

3. Чаты для чтения и отправки

Готово. Telegram подключён.

Открой новую задачу в Codex, выбери плагин Telegram Reader и напиши: «Покажи доступные чаты».

Это окно можно закрыть. Временный сервер настройки остановится автоматически.

Сессия, ключи и тексты исходящих черновиков сохраняются на этом компьютере с шифрованием Windows. Отправка сообщений выполняется по твоему прямому поручению. Чтение истории не отмечает сообщения прочитанными. Переписка, которую ты просишь проанализировать, передаётся в контекст Codex. Скачанные вложения хранятся локально без дополнительного шифрования. Не передавай другим папку данных аккаунта.
